## Turn on GitHub Pages (one-time)

GitHub API cannot enable Pages for this account. In the browser:

1. Open [Settings → Pages](https://github.com/paulnjune2016/welcome/settings/pages)
2. **Build and deployment → Source:** Deploy from a branch
3. **Branch:** `main` · **Folder:** `/ (root)`
4. Save

The site is live at https://paulnjune2016.github.io/welcome/ after about a minute.
